# Fibonacci Series in C++

This is a simple C++ program that generates the Fibonacci Series using Object-Oriented Programming (OOP) concepts.

## 📌 About the Project

The program takes input from the user and prints the Fibonacci sequence up to the given number of terms.

This project is useful for beginners learning:

- C++ Basics
- Loops (`for loop`)
- Classes and Objects
- Functions
- Variables and Logic Building

## 🛠 Technologies Used

- C++
- Standard Input/Output (`iostream`)

## 📂 Program Features

✔ Generate Fibonacci Series  
✔ User Input Support  
✔ Simple and Beginner Friendly Code  
✔ Uses OOP (Class & Method)
